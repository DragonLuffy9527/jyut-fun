一、點解放棄舊方案

原本方案建基於《粵語（香港話）教程（修訂版）》PDF 同配套 MP3，做落去遇到三個硬傷：

問題具體情況
版權風險教材、錄音都係第三方版權物，就算官方公開下載，都唔代表可以直接打包入 App 公開發佈。
內容唔可控掃描版 OCR 有固有錯字，規則救唔返；音頻係整課錄音，冇逐句切分，做唔到「點句子聽句子」。
學習路徑錯配教材按語法體系編排，唔係按「我要去茶樓點餐」呢種真實需求編排，學習者要學好耐先講得出口。
新方案：課程內容 100% 原創編寫，發音 100% 自家合成。冇版權風險、逐句音頻精準對齊、可以自由改寫同擴充。

行內術語要特別小心：呢兩個板塊有唔少「字面一樣、讀法唔同」嘅詞。例如「天秤」指塔式起重機時讀 tin1 cing3，唔係天秤座嘅 tin1 ping4；「轉介」讀 zyun3 gaai3，同「轉車／轉工」一致。呢類詞已經逐個對照權威語料核實，並寫入覆蓋表。

三、粵語配音方案

用微軟 Edge 神經網絡語音（edge-tts）嘅粵語音色，離線生成再打包，唔使 App 內聯網合成。

用途音色說明
A 角色（女）zh-HK-HiuMaanNeural對話用男女雙聲演繹，聽得出邊個講，比單一機械聲自然好多
B 角色（男）zh-HK-WanLungNeural
C 角色（女）zh-HK-HiuGaaiNeural
核心句 / 詞彙zh-HK-HiuMaanNeural統一音色做示範；詞彙語速 −18%，句子 −10%，方便跟讀

完整對話音檔由逐句音檔拼接而成，保留男女對答，唔使額外合成。

額外好處：App 內置「慢速 0.75×」開關，配合慢速錄音，初學者可以逐字跟。

四、粵拼準確性（重點）

你之前反饋過「拼音錯會誤導學習者」，所以呢次粵拼唔靠人手打，全部由開源權威語料庫自動標註：

環節做法
主要標註ToJyutping（基於 rime-cantonese，粵語計算語言學基礎建設組，CC BY 4.0）逐字轉粵拼
交叉驗證用 pycantonese（獨立詞庫）覆核高風險詞，兩個詞庫有分歧就人手裁決
詞級覆蓋已知誤判用覆蓋表精準修正

交叉驗證實際抓出嘅問題

詞ToJyutpingpycantonese裁決
爸爸 / 媽媽baa4 baa1baa4 baa1✅ 兩庫一致 → 變調形式係真實讀音（我原本手寫 baa1 反而係錯）
轉左 / 轉右zyun2zyun3⚠️ 分歧，且與「轉車 zyun3」不一致 → 採用 zyun3
喺度詞級 dou6 / 句級 dok6dou6⚠️ 句級上下文誤判 → 加覆蓋修正為 dou6
坦白講：冇任何自動工具係 100% 準。呢個流程嘅價值係「錯得少 + 錯得可追溯」——詞庫版本同覆蓋表都喺代碼入面，之後發現問題可以隨時補。

七、下一步建議

  1. 擴充課程：現有 30 課可再按需加（例如飲酒文化、寵物、租樓、銀行、投訴），改 tools/curriculum/*.json 再跑一次工具鏈就得。
  2. 間隔重複：生詞本接 SRS 算法（Anki 式），按遺忘曲線安排複習，比單純收集有效得多。
  3. 跟讀打分：錄音比對音高／時長，畀學習者知自己聲調啱唔啱——呢個係粵語學習嘅核心難點。
  4. 落 Flutter 工程：原型驗證完就直接照搬呢個數據結構，音檔放 assets 或 CDN，just_audio + audio_service 做播放核心。
版權狀態：本 App 課程內容同音頻均為本項目原創／合成，冇第三方版權負擔。唯一要注意嘅係粵拼數據來自 rime-cantonese（CC BY 4.0）—— 按該協議需標明出處，App「我的」頁已註明。
