二、發布前必清的兩條紅線

這兩項與技術無關，但任何一項沒處理，上架一定出問題，且都是事後補救極貴的那種。

紅線一：3311 段語音的授權來源

現況 全部語音由 edge-tts 生成。它是社區對 Microsoft Edge「大聲朗讀」功能的逆向封裝，微軟從未授權第三方以這種方式批量調用。個人自用無人追究，但向應用商店分發屬於明確的風險區。

幸運的是，同一條路有完全乾淨的走法：本次使用的音色在 Azure 官方語音服務裡是同名預建神經語音，而微軟產品條款明確允許付費訂閱客戶商用其生成音頻 — 可嵌入產品、可轉售、無需署名。注意兩點：必須使用 pay-as-you-go 付費訂閱（免費額度不得用於商用），且微軟要求對 AI 合成語音做適當披露。

比較項edge-tts（現況）Azure Speech 官方（建議）

為什麼特別強調 這兩批素材是整個專案唯一涉及第三方版權的資產，也是審核最容易直接打回的材料。它們目前就躺在 app/ 目錄底下，而打包工具默認會把 app/ 整個當成 Web 資源目錄 — 一不小心就全打進去了。發布前務必先清空或加排除規則。

三、技術路徑：三選一

方案工作量能上商店優點代價
PWA 網頁版1–2 天否（可上架 Google Play 需 TWA 包裝） 零改造成本，加到主屏即用，可先驗證真實用戶反應 iOS 支援受限、無商店曝光、無法離線分發大量音檔
Capacitor 包殼
建議		3–5 天是（雙端） 現有程式碼 100% 複用；已有驗證過的 UI 與發音路由不用重做 需處理 WebView 儲存與背景播放；須通過蘋果 4.2 最低功能性審查
Flutter 重寫數週是（雙端） 原生體驗最好，背景播放、鎖屏控制最順 UI、發音路由、逐字拼音對齊全部推倒重來，回歸風險高
為什麼建議 Capacitor 這個 App 的形態是「靜態內容 + 本地音頻」，沒有 AR、沒有重度傳感器、沒有複雜原生 UI。它已經被逐項驗證過：66 課全渲染、逐字發音 8169/8169 命中、整句 1506/1506 可讀。用 Flutter 重寫等於把這些驗證全部作廢，換來的體驗提升對內容型 App 而言很有限。包殼能讓你在本週內拿到可提交的安裝包，之後若真需要跟讀打分等重原生能力，再局部遷移也不遲。

包殼前必做的前置改造

1

補 PWA 三件套

manifest.json（名稱、圖示 192/512、主題色、display:standalone）、Service Worker（預快取 index.html + 兩個 JSON 索引）、App 圖示一組。這是 PWA 與包殼共同的前提。

2

把進度儲存從 localStorage 換成原生儲存

iOS 的 WKWebView 會把 localStorage 當可清理快取，系統儲存緊張時直接清空 — 用戶的課程進度與星星會無聲消失。改用 @capacitor/preferences，寫一層儲存適配器替換現有調用即可。

3

處理背景播放與鎖屏控制

WebView 音頻在背景會被暫停。需接原生音頻插件，在 iOS 開啟 UIBackgroundModes: audio，並提供鎖屏播放控制，同時這也是讓審核認定「原生 App」而非「網頁」的重要證據。

4

確保零外部網路請求

所有 JSON 與音檔改為相對路徑內建，移除任何 CDN、字體或分析腳本引用。純離線既能規避「套殼網站」判定，也讓你有可能豁免 ICP 備案。

1

清掉原書素材

五、關鍵路徑：軟體著作權

這是最容易被低估的一件事。把所有環節耗時攤開看，技術工作總共不到一週，資質辦理卻是以月計 — 軟著普通件 60 個工作日，加急也要 20–30 個工作日（找代理約 800–1500 元）。

結論：今天就送軟著 正確的節奏是「送件 → 邊等邊做技術改造 → 邊等邊辦備案 → 證下來直接送審」。若等 App 做完才想起申請，會白白多等兩個月。其餘所有事情都可以與它並行。

6.2 Google Play

項目要求
註冊費$25 一次性
新個人帳號封測2023-11-13 之後建立的個人帳號，必須先跑封閉測試：至少 12 名測試者連續 opt-in 滿 14 天，才能申請正式版發布權限

現實時間預期：約 3 週起。其中 14 天是強制的封閉測試等待期，無法壓縮。 2026 年起 Google 還會查核測試者是否真的在用App，掛名不用會被駁回 —— 這是整個流程最需要提早動手的一件事。

APK 可以直接發給手機安裝嗎？可以 此 APK 內沒有原生庫（0 個 .so），是純 Java/Kotlin + WebView、單一 dex，因此全 ABI 通用（arm64 / armeabi / x86 都能裝）； 最低 minSdk 24（Android 7.0 以上）。因為用自簽上傳金鑰簽署，手機需開「允許安裝未知來源」（各家 UI 名稱不一，通常在 「設定 → 應用程式 → 特殊應用程式存取權」，或安裝時按提示直接開啟）。

⚠️ 一個容易中的坑：因本版換過簽名金鑰（C=HK → C=CN），手機上若已裝過舊版， 必須先卸載再裝新版，否則系統會以 INSTALL_FAILED_UPDATE_INCOMPATIBLE（簽章不符）拒裝 —— 卸載會清掉該機的學習進度。

發送方式：建議雲端硬碟連結、USB 傳輸線或藍牙；即時通訊軟體常把 .apk 改名或直接阻擋，需改成 .apk1 之類再請對方改回。 另：App 內宣告的 INTERNET 權限不是「會上網」 —— Capacitor 用 WebView 內建本機伺服器把 APK 資產以 https://localhost/ 供應，這個權限正是該 loopback 所需，移除反而會壞。
